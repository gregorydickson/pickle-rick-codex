## Trap Doors

- `config-protection.js` — INVARIANT: protected-file checks must shell-tokenize commands before quote stripping and suffix matching. BREAKS: quoted, spaced, or absolute protected paths bypass the config gate and allow unauthorized edits. ENFORCE: `config-protection` quoted-shell-path regressions. PATTERN_SHAPE: protected-path matcher splits shell commands on raw whitespace before token normalization.
- `cancel.js` — INVARIANT: snapshot runtime PIDs before pipeline cancellation clears mirrored state. BREAKS: live verification/codex children survive a cancelled detached pipeline session. ENFORCE: `session-flow` pipeline cancel regression. PATTERN_SHAPE: cancel path reads `active_child_pid` only after `cancelPipelineSession()` / `deactivateSession()`.
- `draft-prd.js` — INVARIANT: bootstrap advances to `refine` only after Codex succeeds; fallback PRDs are artifact recovery only. BREAKS: failed drafting becomes placeholder requirements and misroutes downstream ticket generation. ENFORCE: `command-flows` draft-prd failure regression. PATTERN_SHAPE: bootstrap fallback artifact write before `assertCodexSucceeded(...)`.
- `loop-runner.js` — INVARIANT: anatomy fallback stages tracked edits plus iteration-created untracked files only; preflight skips `??`-only repos. BREAKS: unrelated files enter anatomy commits or launch fails on an empty tracked commit. ENFORCE: `session-flow` anatomy isolation + untracked-only preflight regressions. PATTERN_SHAPE: fallback stages all untracked files or preflight auto-commits without excluding `??`-only porcelain status.
- `spawn-refinement-team.js` — INVARIANT: fallback refinement must succeed before synthesis runs. BREAKS: failed analyst fallback is masked by later synthesis or PRD-table fallback output. ENFORCE: `command-flows` failed-refinement-fallback regression. PATTERN_SHAPE: fallback `runCodexExecMonitored(...)` path advances without `assertCodexSucceeded(...)`.
- `spawn-refinement-team.js` — INVARIANT: synthesis starts only after every analyst exits successfully, writes its role-specific report, and returns the `ANALYST_COMPLETE` promise; incomplete analyst artifacts are discarded and force single-pass fallback. BREAKS: a natural zero exit without the promise is counted as a successful review lens, so synthesis can materialize a plan from incomplete evidence. ENFORCE: `command-flows` incomplete-analyst-contract regression. PATTERN_SHAPE: `runAnalyst(...)` trusts `assertCodexSucceeded(...)` without rechecking the monitored report-and-promise predicate.
- `spawn-refinement-team.js` — INVARIANT: successful single-pass fallback output is the final refinement result; synthesis runs only after all three analysts succeed. BREAKS: synthesis cleanup deletes the recovered `prd_refined.md` and `refinement_manifest.json`, so an analyst failure still aborts or replaces a successful fallback. ENFORCE: `command-flows` successful-fallback materialization regression. PATTERN_SHAPE: unconditional `runSynthesis(...)` after the analyst fallback catch.
- `spawn-refinement-team.js` — INVARIANT: fallback output is committed only when Codex succeeds and writes `prd_refined.md`, `refinement_manifest.json`, and the `REFINEMENT_COMPLETE` promise; incomplete outputs must be discarded before retry/resume. BREAKS: a clean zero exit with a partial manifest becomes executable tickets immediately or after bootstrap sees the surviving manifest. ENFORCE: `command-flows` partial-fallback-output regression. PATTERN_SHAPE: fallback trusts `assertCodexSucceeded(...)` without rechecking the monitored artifact predicate.
- `spawn-refinement-team.js` — INVARIANT: synthesis output is committed only when Codex succeeds and writes `prd_refined.md`, `refinement_manifest.json`, and the `REFINEMENT_COMPLETE` promise; incomplete outputs must be discarded before retry/resume. BREAKS: a valid-looking partial manifest from a clean Codex exit becomes executable tickets, immediately or when bootstrap later sees the surviving manifest. ENFORCE: `command-flows` partial-synthesis-output regression. PATTERN_SHAPE: `assertCodexSucceeded(...)` accepts a natural zero exit without rechecking and cleaning up the monitored artifact predicate.
- `status.js` — INVARIANT: pipeline progress counts only `done` phases plus the current `running` phase. BREAKS: failed/cancelled phases render as completed work and mislead resume triage. ENFORCE: `session-flow` pipeline status regression. PATTERN_SHAPE: `completedPhases + 1` on non-complete current phase without checking `phaseStatuses[currentPhase]`.
