## Trap Doors

- `config-protection.js` — INVARIANT: protected-file checks must shell-tokenize commands before quote stripping and suffix matching. BREAKS: quoted, spaced, or absolute protected paths bypass the config gate and allow unauthorized edits. ENFORCE: `config-protection` quoted-shell-path regressions. PATTERN_SHAPE: protected-path matcher splits shell commands on raw whitespace before token normalization.
- `cancel.js` — INVARIANT: snapshot runtime PIDs before pipeline cancellation clears mirrored state. BREAKS: live verification/codex children survive a cancelled detached pipeline session. ENFORCE: `session-flow` pipeline cancel regression. PATTERN_SHAPE: cancel path reads `active_child_pid` only after `cancelPipelineSession()` / `deactivateSession()`.
- `draft-prd.js` — INVARIANT: bootstrap advances to `refine` only after Codex succeeds; fallback PRDs are artifact recovery only. BREAKS: failed drafting becomes placeholder requirements and misroutes downstream ticket generation. ENFORCE: `command-flows` draft-prd failure regression. PATTERN_SHAPE: bootstrap fallback artifact write before `assertCodexSucceeded(...)`.
- `loop-runner.js` — INVARIANT: anatomy fallback stages tracked edits plus iteration-created untracked files only; preflight skips `??`-only repos. BREAKS: unrelated files enter anatomy commits or launch fails on an empty tracked commit. ENFORCE: `session-flow` anatomy isolation + untracked-only preflight regressions. PATTERN_SHAPE: fallback stages all untracked files or preflight auto-commits without excluding `??`-only porcelain status.
- `spawn-refinement-team.js` — INVARIANT: analyst, synthesis, and fallback workers run as leaf processes from isolated artifact directories with safe per-call Codex arguments and no writable repository/session add-dir. BREAKS: a refinement worker mutates product code or canonical control artifacts before validation. ENFORCE: `command-flows` isolated refinement invocation regression. PATTERN_SHAPE: worker cwd points at `working_dir`/session, inherits global bypass arguments, or receives a session add-dir.
- `spawn-refinement-team.js` — INVARIANT: all analyst attempts settle; successful role checkpoints are non-empty and bound to PRD, prompt contract, and a clean repository revision before reuse. BREAKS: one transient role failure kills healthy peers, stale analysis is reused after source/code changes, or fallback overlaps analysts. ENFORCE: `command-flows` incomplete-analyst and failed-fanout-drain regressions. PATTERN_SHAPE: fail-fast `Promise.all(...)`, existence-only checkpoints, or unbounded analyst retries.
- `spawn-refinement-team.js` — INVARIANT: final artifacts remain candidates until the production validator accepts a fresh Todo-only manifest; one bounded repair receives exact rejection diagnostics. BREAKS: malformed or semantically invalid output becomes executable, recoverable synthesis restarts all analysis, or rejected output overwrites the last accepted plan. ENFORCE: `command-flows` semantic-repair and canonical-preservation regressions. PATTERN_SHAPE: model writes canonical paths, validation happens after promotion, or retry prompt omits validator findings.
- `spawn-refinement-team.js` — INVARIANT: canonical refined PRD, manifest, materialized tickets, and hash-bound acceptance receipt are promoted in that order before state advances to research. BREAKS: controller crashes leave an existence-only manifest that bootstrap executes or source PRD edits retain stale tickets. ENFORCE: refinement acceptance/readiness regressions. PATTERN_SHAPE: readiness checks only manifest existence or promotion writes its receipt before ticket materialization.
- `spawn-refinement-team.js` — INVARIANT: refinement and ticket execution share one live session-operation lease; every parallel refinement child identity is persisted, cancellable, and recovered before restart. BREAKS: mux execution races refinement, cancellation leaves analysts running, or a controller crash wedges/duplicates the run. ENFORCE: concurrent-cancel and operation-lease regressions. PATTERN_SHAPE: only one active child PID is stored, dead-owner locks retain the stale grace, or refinement/mux use unrelated leases.
- `status.js` — INVARIANT: pipeline progress counts only `done` phases plus the current `running` phase. BREAKS: failed/cancelled phases render as completed work and mislead resume triage. ENFORCE: `session-flow` pipeline status regression. PATTERN_SHAPE: `completedPhases + 1` on non-complete current phase without checking `phaseStatuses[currentPhase]`.
